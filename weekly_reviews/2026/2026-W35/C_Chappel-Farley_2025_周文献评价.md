Individual differences in medial temporal lobe functional network architecture predict the capacity for sleep-related consolidation of emotional memories in older adults

## Original Abstract

Study Objectives: Memory consolidation during non-rapid eye movement slow wave sleep (NREM SWS) involves reactivation of a hippocampal index which integrates distributed cortical representations of an experience. This study examined whether individual differences in brain network properties that align with this theoretical organization were associated with interindividual variability in memory consolidation during sleep. Methods: Thirty-six older adults (μage = 72.9 ± 5.6) completed overnight polysomnography with pre- and post-sleep emotional memory testing. Slow oscillation (SO) power and SO-sleep spindle (SO-SP) coupling were computed. Participants also completed 3T structural and resting-state functional magnetic resonance imaging (rsfMRI). Resting-state fMRI network modularity (Q), hippocampal and amygdala eigenvector centrality (EC), and betweenness centrality (BC) were calculated. Results: Greater Q was associated with reduced emotional memory retention and greater SWS. Hippocampal and amygdala EC were associated with better emotional memory retention. Hippocampal BC was associated with immediate test performance, whereas amygdala BC was associated with delayed test and memory retention. Hippocampal centrality measures were associated with SO power and SO-SP coupling. Random forest classification revealed distinct network measure combinations predict different stages of memory processing. Conclusions: Network integration supports overnight emotional memory retention. Individuals with more influential medial temporal lobe nodes exhibited better memory consolidation, suggesting functional network architecture contributes to memory processing. These measures were associated with sleep oscillations implicated in consolidation. Individual differences in functional network organization may predict the capacity of older adults to consolidate memories.

## 中文摘要

研究目的：非快速眼动慢波睡眠（non-rapid eye movement slow wave sleep，NREM SWS）期间的记忆巩固涉及“海马索引（hippocampal index）”的再激活，该索引整合一次经验分布于皮层各处的表征。本研究考察：与这种理论组织形式相一致的脑网络属性的个体差异，是否与睡眠期间记忆巩固的个体间差异相关。 方法：36 名老年人（平均年龄 72.9±5.6 岁）接受整夜多导睡眠监测，并在睡眠前后完成情绪记忆测试。研究计算慢振荡（slow oscillation，SO）功率以及 SO-睡眠纺锤波（SO-SP）耦合。参与者还完成 3T 结构磁共振与静息态功能磁共振成像（rsfMRI）。研究计算静息态 fMRI 网络模块化程度/模块度（Q），以及海马与杏仁核的特征向量中心性（EC）和介数中心性（BC）。 结果：较高的 Q 与较差的情绪记忆保持以及更多的 SWS 相关。海马和杏仁核 EC 越高，情绪记忆保持越好。海马 BC 与即时测试表现相关，而杏仁核 BC 与延迟测试表现及记忆保持相关。海马中心性指标还与 SO 功率及 SO-SP 耦合相关。随机森林分类显示，不同网络指标组合对不同记忆加工阶段具有不同的统计预测价值。 结论：网络整合有利于隔夜情绪记忆保持。内侧颞叶节点在功能网络中影响力更强的个体表现出更好的记忆巩固，这提示功能网络结构与记忆加工相关。这些网络指标还与被认为参与巩固的睡眠振荡相关。功能网络组织的个体差异可能有助于预测老年人巩固记忆的能力。

## 评论

该研究关注的是为什么同为认知健康的老年人，睡眠后的情绪记忆保持能力仍存在明显个体差异？作者把静息态功能磁共振的图论网络指标、整夜多导睡眠监测以及睡前—睡后的情绪记忆辨别任务结合起来，尝试把经典的海马索引、网络模块化/整合和睡眠依赖性记忆巩固理论映射到可量化的个体差异指标。研究最终纳入36名平均年龄72.9岁的认知健康老年人，要求他们在实验中完成情绪性记忆辨别任务，并接受整夜多导睡眠监测；并在另一时间完成结构磁共振和静息态功能磁共振检查，实验与检查平均相隔约1.26年，时间顺序不分先后。此外，研究者利用静息态功能磁共振数据评估整体脑网络的模块化和整合程度，以及海马和杏仁核在脑网络中的重要性及其参与信息传递的程度；同时在部分被试中进一步分析慢振荡功率和慢振荡—睡眠纺锤波耦合。

研究中的不同指标与不同记忆阶段形成了相对清晰的对应。较高的海马和杏仁核特征向量中心性（EC）与更好的隔夜负性情绪记忆保持相关；海马介数中心性（BC）主要与睡前即时测试表现相关，而杏仁核介数中心性（BC）与隔夜保持和第二天延迟测试相关。共同性分析还显示，海马和杏仁核特征向量中心性（EC）既包含独立贡献，也包含较大的共享成分。这与海马形成并区分事件表征、杏仁核调节情绪显著性的理论框架较为一致。海马特征向量中心性（EC）还与前额慢振荡—纺锤波耦合显著相关，使清醒期的内在网络结构与睡眠期巩固相关振荡之间建立了联系。

关于网络模块度Q的结果。研究者原先假设更高Q，即更模块化的网络，会同时对应更多NREM慢波睡眠和更好的隔夜保持。结果显示，高Q确实与更多SWS相关，但记忆方向相反：在低干扰负性材料中，Q越低、网络越整合，隔夜保持越好。作者据此提出，SWS虽然整体更偏模块化和局部处理，但慢振荡可能为跨区域长程通信提供时间窗口，因此模块化与巩固所需的整合并不必然矛盾。但研究中并没有正式检验“Q→SWS→记忆”的中介路径，并且SWS与记忆保持在原先将高、低相似度诱饵合并的分析中并不显著，只有进一步限制到低相似度、低干扰条件后才达到显著，因此这部分证据只被视为进一步的探索性结果。

方法上，该研究整合了静息态fMRI、睡眠监测和脑网络分析，具有一定创新性，但也存在一些限制。静息态fMRI与睡眠实验平均相隔1.26年，因此这些脑网络指标只能视为较稳定的个体特征，不能代表睡眠当晚的脑网络状态。部分fMRI扫描视野有限，最终分析仅包含脑网络组图谱中151个被充分覆盖的脑区，因此网络模块度反映的是这一部分脑网络的组织特征。此外，睡眠振荡分析的样本量也较小，慢振荡功率分析仅18人，慢振荡—纺锤波耦合分析仅16人，部分结果在控制年龄和性别后不再显著。随机森林分析同样只有36人，并将连续的记忆成绩按中位数分组，可能损失部分信息。

总体而言，这篇研究的优势不在于单独某一种方法，而在于提出了一个可以继续验证的“清醒期内在网络结构—睡眠生理—情绪记忆加工”框架。未来的睡眠记忆研究可以从单纯比较睡眠阶段时长，进一步转向网络拓扑、睡眠振荡和行为精细指标的联合建模，进一步判断这些网络指标究竟只是稳定的个体标志物，还是能够参与并预测睡眠依赖性情绪记忆巩固的真实机制。
