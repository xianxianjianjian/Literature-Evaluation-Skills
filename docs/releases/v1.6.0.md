# Literature Evaluation v1.6.0

This release delivers structural refactoring, repository data separation, version single-source-of-truth enforcement, modular script packaging, and automated local deployment while keeping all academic and archive validation contracts unchanged.

## Changes

- **Research Archive Separation**: Move live and historical research records (`knowledge/` and `weekly_reviews/`) out of the plugin source repository into a dedicated standalone research Git repository with commit history and SHA provenance preserved. The plugin repository retains only clean workspace templates (`assets/workspace-template/`) and sanitized regression fixtures (`tests/fixtures/legacy/`).
- **Plugin UI Icon & Version Single Source of Truth**: Add `assets/literature-evaluation.svg` (`interface.logo` and `interface.composerIcon`) to `.codex-plugin/plugin.json`, and enforce version synchronization across `.codex-plugin/plugin.json`, `README.md`, and `docs/architecture.md` via `scripts/validate_plugin_package.py`.
- **Skill Routing Slimming & Legacy Compatibility**: Deduplicate the status-refresh and SI-bundle instructions across the four `SKILL.md` files into `shared/state-contract.md` and `docs/paper-status-and-si.md`, and consolidate v1.2–v1.5 backward-compatibility rules into [`docs/legacy-compatibility.md`](../legacy-compatibility.md).
- **Modular Script Packaging**: Add `scripts/__init__.py` and split thousand-line modules into focused submodules (`validate_translation_package.py` + `translation_exact_validator.py`; `zotero_bridge.py` + `zotero_role_archive_ops.py`) while preserving every CLI script name and module import surface.
- **Automated Local Deployment**: Add `scripts/deploy_local_plugin.py` to execute bundle building, package validation, temporary-workspace foundation checks, optional cache installation, `workspace.json.plugin_root` updates, and `<bundle>.build.json` provenance recording in a single command.

## Validation and Compatibility

All existing academic and archive red lines remain unchanged:

- The four Skill entry points (`weekly-literature-evaluation`, `literature-search`, `paper-translation`, `paper-deep-reading`) and the two fixed human confirmation Gates are unchanged.
- Academic completion and Zotero archive completion remain separate; `FULL_MIRROR / EXACT_TEXT_FRAME / SimSun / 0.95` defaults, SHA-256 content bindings, and Naming v1/v2 backward readers remain intact.
- Issue #15 (human A reader sampling, C academic signoff, and corrected-A Zotero reconciliation) remains tracked separately on the research side; this software release does not fabricate or close human research-artifact acceptance.

## Install and Rollback

Use `scripts/deploy_local_plugin.py` (see [`docs/local-plugin-updates.md`](../local-plugin-updates.md)) to build a versioned bundle under `deployments/`, validate the package and an isolated temporary workspace, update `workspace.json.plugin_root`, and record the rollback marketplace bundle in `.build.json`. Verify the four Skill loading paths in a fresh chat session after installation.
