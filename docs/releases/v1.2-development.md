## Purpose

v1.2 was a development milestone rather than an independently published release. Its complete change set is inherited by the v1.3.0 release candidate in PR #9. No `v1.2.0` release tag is intended.

## Translation evidence hardening

- Added explicit translation scope: `FULL_MIRROR`, `MAIN_ONLY`, and `ABSTRACT_ONLY`.
- Added `source_inventory.json`, `translation_ledger.jsonl`, `translation_issues.jsonl`, and FULL_MIRROR layout-evidence contracts.
- Recomputed Main/SI source-unit, page, object and table coverage rather than trusting hand-authored QC claims.
- Added rendered-page validation and failure cases for missing figures, flattened table topology, and broken source/output mappings.

## Psychology and cognitive-neuroscience deep reading

- Added a three-pass psychology deep-reading route.
- Added design-appropriate routing to APA JARS, STROBE, CONSORT-SPI, JARS-Qual, MMARS, COBIDAS, and mediation/SEM considerations.
- Required interpretation of estimates, uncertainty, effect sizes, scientific meaning, and analysis-specific N rather than p-threshold-only conclusions.
- Added deterministic DOCX metadata/comment sanitation and direct package validation.
