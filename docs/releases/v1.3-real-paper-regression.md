Status: **Release-candidate evidence; copyrighted source PDFs are not committed to this repository.**

This record summarizes regression checks performed against user-supplied 2025 psychology / cognitive-neuroscience journal PDFs. Only structural metadata and implementation findings are recorded here; source-paper content is not redistributed.

## Findings and fixes

### 1. Parallel journal columns

Initial real-paper extraction exposed cross-column line concatenation. The extractor was changed to split spatially separated text runs before paragraph grouping. Regression tests now prohibit a left and right journal column from entering one translation frame.

Result: **PASS after fix.**

### 2. Word spacing

Initial extraction discarded or failed to infer some word boundaries. The extractor now preserves explicit PDF spaces and infers missing boundaries from glyph geometry.

Result: **PASS after fix.**

### 3. Rotated publisher/download furniture

Vertical outer-margin download/publisher strings in journal PDFs generated meaningless one-character replacement frames. They are now classified as retained identifiers (`RETAIN_SOURCE`, reason `IDENTIFIER`) and excluded from translation frames. Rotated content-stream order is not treated as semantic because retained furniture is never translated.

Result: **PASS after fix.**

### 4. Supplementary manuscript line numbers

The Sjøgård SI uses sequential line-number gutters. These are now detected as retained identifiers rather than translation units.

Result: **PASS in synthetic regression covering the real pattern.**

### 5. Table segmentation

Real SI material covers both borderless and ruled tables. Extraction now keeps detected table cells separate and prevents row/column fragments from being merged into paragraph frames. Synthetic regression covers ruled and conservative borderless table cases.

Result: **PASS for structural extraction gate. Representative translated-table replacement geometry also passed the pixel-preservation check described below.**

### 6. Shifted typographic ligatures

The Sjøgård Main PDF exposed `ﬁ` / `ﬂ` glyphs whose bounding boxes are vertically shifted relative to neighboring letters. With a fixed 2 pt line tolerance these glyphs could become isolated translation frames and leave damaged source words.

The extractor now:

- applies a font-size-relative vertical tolerance only when a candidate line contains `ﬀ`, `ﬁ`, `ﬂ`, `ﬃ`, or `ﬄ`;
- keeps the strict normal tolerance for ordinary glyphs so adjacent lines are not broadly merged; and
- normalizes these ligatures in `source_text` to `ff`, `fi`, `fl`, `ffi`, and `ffl`.

Local reruns across all five supplied PDFs produced zero isolated typographic-ligature translation frames. A dedicated non-copyright synthetic regression test was added.

Result: **PASS after fix and normal CI confirmation.**

## Production SimSun gate

The GitHub Actions Windows production-font job uses the runner's actual `C:\\Windows\\Fonts\\simsun.ttc`; no font binary is stored or redistributed by this repository.

The production gate verifies:

- the required `simsun.ttc` file exists;
- TTC face 0 identifies as `SimSun` / `宋体`;
- required Chinese glyphs and punctuation exist;
- ReportLab can embed the actual font in a generated PDF;
- embedded Chinese text round-trips through PDF extraction; and
- synthetic bold and italic rendering paths complete.

Observed result on the Windows release runner: **PASS**.

## Representative real-page replacement geometry

A separate local regression used the private source PDFs directly, but used a non-copyright synthetic SimSun test double for geometry only. This test is deliberately independent of the production-font evidence above: the Windows gate proves the actual SimSun runtime; the private real-page test proves replacement geometry against real journal pages without redistributing either the font or the papers.

Representative replacements covered:

- a Lee supplementary-table label;
- a Lee supplementary timeline caption; and
- two Sjøgård supplementary table labels on a page that also contains a large cortical figure.

For the generated representative outputs:

- source and output page counts were identical;
- MediaBox, CropBox, TrimBox, BleedBox, ArtBox, and page rotation remained identical on every page;
- all selected translations fit at 100% source font size; and
- at 144 dpi, after masking only the allowed replacement rectangles, **zero changed pixels** remained elsewhere on the tested Lee and Sjøgård pages.

The synthetic geometry font intentionally has placeholder glyph outlines, so this check does not claim visual font fidelity. Actual SimSun identity, glyph coverage, embedding, extraction round-trip, bold, and italic are proven separately by the Windows production-font gate.

Result: **PASS for representative real-page geometry/non-text preservation.**

## 100%–95% fitting boundary on a real-paper frame size

A non-copyright regression fixture now uses dimensions rounded from a private real supplementary-table text frame, without including source-paper text.

With the current renderer's fixed scale sequence (`1.00, 0.99, 0.98, 0.97, 0.96, 0.95`):

- an 11-CJK-character stress string does not fit at 100% but fits at **97%**; and
- a 12-CJK-character stress string does not fit even at **95%**, so `_layout()` returns no fit and the renderer's overflow path remains mandatory rather than silently shrinking below the contract floor.

Result: **PASS; covered by `tests/test_v13_real_bbox_fitting.py`.**

## CI confirmation

The release-candidate head containing the extraction fixes, ligature regression, production SimSun job, and real-bbox fitting tests passed the normal pull-request workflow on Linux Python 3.11/3.12 and the Windows production-font job. The copyrighted real-paper files themselves remain outside CI.

## Remaining strict acceptance boundary

The combined evidence now covers real-source intake, Main/SI page mapping, mixed-page geometry, columns, spaces, rotated publisher furniture, SI line-number gutters, table segmentation patterns, ligatures, actual Windows SimSun, representative real-page Chinese replacement geometry, non-text preservation, and real-bbox 100%–95%/overflow behavior.

For the strictest possible release definition, one item remains distinct from these split-environment checks: a **complete translated FULL_MIRROR Main+SI package** in which every translation unit has real Chinese text, rendered with actual SimSun on the same Windows environment, followed by independent package validation and full-page visual QC. That requires the copyrighted source PDFs and completed translation ledger to be present in the same production Windows execution context. Until that exact end-to-end package is run, this record should not claim that a full real-paper A deliverable has been acceptance-tested end to end.
