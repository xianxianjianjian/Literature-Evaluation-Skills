# v1.5.0 development notes

This branch updates the A/B/C and Zotero contracts. No release tag has been created.

- A: reviewed source text objects are removed before Chinese text insertion. The new text-layer validator checks extraction, copying, search, stale English, order and ToUnicode; visual reader selection still needs review.
- B: DOCX remains the editable academic source; a passed independent render is promoted to a checked PDF for archive.
- C: new submissions use an 800–1000 visible-character review body, Main-visible paper facts, author-acknowledged limitations by default and a private source map. Earlier C files keep their historical contract.
- Zotero: display titles are `pdf`, `SI`/`SI-n`, `A翻译`, `B精读`; data SI retains its native file. Title normalization is dry-run by default and never deletes old attachments.
- Academic completion and Archive completion remain separate. The latter requires B PDF export, role verification and no pending Zotero actions.
- Terminology: the existing registry becomes a context-aware cross-paper psychology database with Domain/Subdomain, operational use, traceable citations, usage count and append-only correction events. Legacy headers remain readable.
- Typography: one paragraph-style engine distinguishes Chinese body, English body, abstracts, headings, captions, table cells, footnotes and APA-style references. Chinese justification is explicitly a project rule, while APA-oriented English prose remains left aligned and references use a 0.5-inch hanging indent.
- Exact Mirror: Chinese body indentation/justification is applied only at the already selected source-safe scale; otherwise a named `LAYOUT_EXCEPTION` retains source-frame formatting without permitting overflow, clipping or geometry changes.
