# Literature Evaluation v1.5.0 — software release notes

> **Release scope:** v1.5.0 software/workflow features. **Manual research-artifact acceptance remains open.** This is not a claim that all Viselli A/B/C scholarly deliverables have completed human review.
>
> **Post-release acceptance tracker:** [Issue #15](https://github.com/xianxianjianjian/Literature-Evaluation-Skills/issues/15).
>
> **Merged implementation:** [PR #14](https://github.com/xianxianjianjian/Literature-Evaluation-Skills/pull/14). 

## Highlights
- **A mirror translation:** better exact-frame text replacement, selectable/copyable/searchable Chinese text, complete mixed-language/number/statistical-value checks, stale-English detection, reading order, ToUnicode, source geometry and font-style quality gates.
- **B deep reading:** DOCX remains editable; independent PDF rendering, all-page visual QA, metadata hygiene, content and SHA-256 provenance binding before archival.
- **C literature review:** 800–1000 visible characters for new v1.5 deliverables, Main-only claim-source map, author-vs-evaluator interpretation checks, and human scholarly signoff requirement; historical C contracts remain versioned.
- **Cross-paper psychology terminology:** context-aware term selection, provenance, usage history and append-only corrections.
- **Bilingual typography:** project-specific Chinese paragraph styles and APA-oriented English/reference styles with source-safe Exact Mirror layout exceptions.
- **Zotero:** Main, documentary SI, A and B role/title/MIME/attachment checks, content identity verification and separate academic/archive completion states.
- **Compatibility:** historical v1.4.1/v1.4.2 manifests, old C character thresholds, existing archives and terminology registries remain readable.

## Installation and rollback
- Build/install the plugin from the exact GitHub v1.5.0 release commit/tag once published, not from a stale Codex cache. Confirm the four Skill entry points and workspace/plugin separation.
- Back up the writable workspace, Zotero attachment identities and manifests before migration.
- Keep the previously built **v1.4.2** plugin bundle available for rollback. Never overwrite or auto-migrate original research records without explicit permission.

## Packaging exclusions
Research PDFs/DOCX, individual work directories, Zotero databases, cache files, local private paths and commercial fonts are **not** shipped with the source release.
