# Literature Evaluation v1.5.1

This release promotes the software accepted in PR #17 to a stable plugin version. It does not certify completion of individual papers or authorize automatic archive cleanup.

## Changes

- Keep private paper platform observations in the research workspace and rebuild a seven-column Markdown/CSV overview, including persistent intake, historical snapshots, identity reconciliation and offline evidence preservation.
- Check current C content against local Git, live remote Git and configured publication pages; preserve manual wording decisions and expose publication conflicts.
- Introduce attachment naming version 2 independently of academic contract version 1.5.0: Main Article, Support Information, A-Translation, B-DeepReading and separately numbered video/data SI.
- Merge documentary SI in source order with page coverage, bookmarks and representative-page rendering checks. Retain original sources and recoverable conversion/QC progress.
- Require final PDF QC binding for A/B archival; preserve the editable local B DOCX and legacy attachment/report readers. Preview title migration and preserve attachment identities.

## Validation and compatibility

The accepted development commit is `042666af7bebc03e1b78ec71382da6c83d5103af`; PR #17 was squash-merged as `39da9955a6bebe278bc5d536984356ca81d029da`. Release preparation changes only the plugin version, README and these release notes; runtime code is unchanged.

Recorded validation includes 336 local regression tests, 40 mandatory real-SimSun tests, package validation, fresh-chat loading and green Linux Python 3.11/3.12 plus Windows SimSun CI. Windows mixed-SI acceptance used real PDF, binary DOC and DOCX through LibreOffice: five pages in source order (1, 2–3, 4–5), with tables, images and equations visually checked. One Support Information attachment was read back byte-for-byte; repeat operations reused the same artifact and attachment. Test evidence and the unchanged thirteen-paper private overview remain outside the plugin repository.

Academic completion, FULL_MIRROR/EXACT_TEXT_FRAME, the four skill entry points and existing A/B/C QC remain unchanged. Existing research-artifact human acceptance in Issue #15, ambiguous Zotero parent selection and publication wording/duplicate decisions remain separate research tasks. No original attachments are deleted or overwritten by this software release.

## Install and rollback

Build from the final `v1.5.1` tag after its commit passes normal CI, validate the package and an independent temporary workspace, then install using [local plugin updates](../local-plugin-updates.md). Confirm actual skill paths in a fresh chat and refresh the private overview. Keep the accepted 1.5.1-dev package available for rollback; do not remove the research data root when switching packages.
