# Literature Evaluation Plugin V1.3.0

## Exact text-frame mirror

- Redefines new `FULL_MIRROR` work as `EXACT_TEXT_FRAME` by default; structural mirror layout requires an explicit user choice.
- Keeps source/output pages one-to-one and preserves all page boxes, rotation, columns, figures, tables and non-text pixels.
- Requires reviewed `text_frame_inventory.jsonl`, strict `font_map.json`, schema-v2 source/layout evidence and frame-level translated text.
- Renders Chinese with embedded Windows SimSun only, using source size through a fixed 95% floor without changing frame geometry or leading.
- Keeps an overflowing, non-uniform-background, or missing-SimSun artifact `PROVISIONAL`/`BLOCKED` instead of adding pages or silently reflowing it.

## Independent validation

- Recomputes PDF page geometry, one-to-one source mapping, replacement-frame containment, table cells, CJK font use and actual glyph sizing.
- Uses same-renderer raster comparison to require zero changed pixels outside reviewed replacement frames.
- Generates `layout_diff.json`; hand-written render notes are diagnostic only.
- Keeps v1 schema packages readable as `LEGACY_STRUCTURAL` but never re-certifies them as exact mirrors.

## Runtime and compatibility

- Exact rendering uses pypdf, pdfplumber, reportlab, Pillow, NumPy, fontTools and Poppler. The Codex desktop PDF runtime provides these capabilities; standalone CI installs `requirements-exact-mirror.txt` and Poppler.
- The SimSun font file is never committed. Missing or non-embeddable `simsun.ttc` is a hard blocker.
- Search, Zotero and Deep Reading academic logic are unchanged.
