# Literature Evaluation Plugin v1.4.1

## Scope

This patch hardens A exact-mirror Chinese typography after the Yuksel 2025 21-page regression exposed cross-column frame merging, visible source English, heading concatenation, mechanical character spacing and fragile numeric typography.

## Changes

- exact frames now carry explicit translatable/replacement and clearing/render/residual lifecycle fields;
- Chinese normalization preserves hard breaks and semantic citation, statistic, unit, group-code and scientific-notation tokens;
- citations use actual PDF text rise with comma lists and en-dash ranges;
- body-like frames may fit at 95%-110% with 1.15-1.45 leading while geometry stays frozen;
- `typography_fit.json` records source/target used height per translated frame;
- `untranslated_residual_audit.json` independently compares source and output frame OCR, rejecting surviving unapproved English runs of four or more words;
- Yuksel page 1's incorrectly merged cross-column frame is split in the regression fixture.

No release tag is created until package installation and remote verification finish.
