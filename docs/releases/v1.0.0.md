# Literature Evaluation Skills V1.0.0

Release date: 2026-08-21

Release commit on `main`: `9a2f6e4c148f82853101d706751123afd91d3f20`

## Release scope

V1.0.0 is the first stable release of the complete usable academic workflow:

```text
weekly-literature-evaluation
        |
        |-- literature-search
        |-- paper-translation
        `-- paper-deep-reading
```

It supports the full weekly route:

```text
research context/history
→ topic candidates
→ Gate 1: user confirms topic
→ Journal Mapping + Search Strategy
→ Round 1 + Round 2 screening
→ Integrity Check + Primary/Alternatives
→ Gate 2: user confirms focal paper
→ source/Main/SI intake
→ Translation + A
→ Deep Reading + B
→ C
→ knowledge/history update
→ optional Zotero archive reconciliation
```

## Core deliverables

- **A** — Chinese full-text mirror PDF.
- **B** — complete research-note DOCX.
- **C** — weekly literature-evaluation submission.

## Evidence and audit guarantees

V1.0.0 freezes the following contracts:

- important conclusions remain traceable to source locations;
- `【原文直接内容】`, `【作者解释】`, `【评译者分析】`, and `【外部依据 EXT-xxx】` remain distinct;
- Main and SI are audited as one evidence package;
- missing information is labeled rather than reconstructed from common practice;
- total N is not substituted for unknown model-specific N;
- prespecified non-significant findings remain represented;
- author interpretation and evaluator critique remain separate;
- statistical inconsistencies are audited rather than silently corrected;
- Canonical Abstract is reused across A/B/C;
- terminology identity is context-sensitive and evidence-backed.

## Completion model

V1.0.0 separates two completion dimensions.

### Academic workflow COMPLETE

Search, Translation/A and Deep Reading/B/C may reach academic completion when their evidence, artifact and QC conditions pass, even if automatic Zotero writing is unavailable.

### Zotero archive COMPLETE

Zotero remains the preferred long-term archive for Main/SI/A/B. Pending or unavailable Zotero writes must be recorded truthfully in `pending_zotero_actions`; they do not invalidate otherwise complete academic work.

Strict archive closure remains separately verifiable.
