# Workflow Specification

## Standard Flow

```text
Research background
→ Topic candidates
→ Gate 1: topic confirmation
→ Literature search
→ Gate 2: paper confirmation
→ Source/Main/SI intake
→ Translation + A
→ Deep Reading + B
→ C submission draft
→ Knowledge/history update
```

## Evidence Contract

Separate:

- Original paper content
- Author interpretation
- Evaluator analysis
- External evidence

Important claims should preserve source anchors whenever possible.

## Completion Model

Academic workflow completion and Zotero archive completion are independent states.
