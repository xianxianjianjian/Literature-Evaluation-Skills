# Validation Specification

## Validation Philosophy

Validation ensures that generated research outputs remain reproducible and traceable.

## Automated Checks

The repository validates:

- Python compatibility.
- Plugin structure.
- Skill discovery.
- Deliverable consistency.
- Rendering and translation constraints.

## CI Requirements

Protected main branch requires:

- Python 3.11 smoke tests.
- Python 3.12 smoke tests.
- Windows SimSun production validation.

## Completion Levels

Academic completion and archive completion are separated.

Academic completion verifies that research workflow requirements are satisfied.

Archive completion additionally verifies long-term storage requirements such as Zotero records.

## Principle

Validation prevents silent failures but does not replace academic judgment.
